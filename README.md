# Montagem de Orquestras em Geral
Criei esse projeto em colaboração com 5 colegas para uma organização que fazia montagem de instrumentos de orquestras
Como precisavam de uma identidade visual para sua empresa, acabamos ajudando a montar seu portifólio!

**Liguagens usadas:** Html, Css, Node.js, Tailwind.
